## 1. 著录体制选择

| 体制 | 标注形式 | 适用 |
|---|---|---|
| 顺序编码制（默认） | 上标 [1] | 理工科期刊、学位论文（多数国内期刊） |
| 著者-出版年制 | (张三, 2020) | 人文社科、部分期刊 |

不确定时默认顺序编码制；用户指定目标期刊时以其投稿须知为准。

## 2. 文献类型标识码

| 标识 | 类型 | 标识 | 类型 |
|---|---|---|---|
| M | 专著 | J | 期刊文章 |
| D | 学位论文 | C | 会议录/论文集 |
| N | 报纸文章 | S | 标准 |
| P | 专利 | R | 报告 |
| G | 汇编 | A | 档案 |
| DB | 数据库 | EB | 电子公告 |
| OL | 在线/联机 | Z | 其他 |

电子资源组合：[J/OL]、[M/OL]、[DB/OL]、[EB/OL] 等。

## 3. 各类型著录格式与示例

**基本结构**：主要责任者. 题名: 其他题名信息[文献类型标识]. 其他责任者. 版本项. 出版地: 出版者, 出版年: 引文页码[引用日期]. 获取和访问路径. DOI.

**专著 [M]**
```
[1] 张三. 高等教育学概论[M]. 2版. 北京: 高等教育出版社, 2019: 45-48.
[2] SMITH J K. Research methods in education[M]. 3rd ed. London: Routledge, 2018: 102-115.
```

**期刊文章 [J]**（最常用）
```
[3] 李四, 王五. 深度学习在医学影像中的应用研究[J]. 计算机学报, 2023, 46(5): 887-901.
[4] WANG L, ZHANG H, CHEN Y. A survey of transformer models[J]. Nature Machine Intelligence, 2022, 4(9): 756-766.
```

**学位论文 [D]**
```
[5] 赵六. 基于图神经网络的推荐算法研究[D]. 上海: 复旦大学, 2021.
```

**会议论文 [C]**
```
[6] CHEN X. Semantic segmentation for autonomous driving[C]//Proceedings of the IEEE CVPR 2023. Vancouver: IEEE, 2023: 1234-1241.
```

**标准 [S]**
```
[7] 中华人民共和国国家质量监督检验检疫总局. 信息与文献 参考文献著录规则: GB/T 7714—2015[S]. 北京: 中国标准出版社, 2015.
```

**专利 [P]**
```
[8] 刘七. 一种基于区块链的数据存储方法: CN202110123456.7[P]. 2021-03-15.
```

**电子资源 [EB/OL]、[J/OL]**
```
[9] 世界卫生组织. 全球健康统计报告[EB/OL]. (2024-01-15)[2025-03-01]. https://www.who.int/data/reports.
[10] 王九. 机器学习的可解释性研究[J/OL]. 计算机研究与发展, 2024, 61(2): 1-15[2025-03-01]. https://doi.org/10.7544/issn1000-1239.2024.20230901.
```
电子资源必须有：更新/修改日期（圆括号）+ 引用日期（方括号）+ URL，三者缺一不可（无更新日期可省圆括号项）。

**预印本**（按电子资源或平台惯例）
```
[11] BROWN A, et al. Large language models for scientific discovery[EB/OL]. (2023-11-30)[2025-03-01]. https://arxiv.org/abs/2311.12345.
```

### 著录细则

- **作者**：≤3 位全部列出，逗号分隔；>3 位列前 3 位后加", 等"（中文）或", et al"（英文）。
- **外文作者**：姓全大写在前，名缩写在后不加缩写点，如 "EINSTEIN A"。题名首词及专有名词大写，其余小写（句式大写）。
- **标点**：中文文献用中文标点；西文文献用半角标点。同一文献表内风格按文献语言各自统一。
- **期刊卷期页**：年, 卷(期): 起-止页。页码用半角连字符。
- **中文期刊含 DOI 时**：在末尾著录 `DOI: 10.xxxx/xxxxx.`。
- **版次**：第 1 版不著录；"2版""3rd ed."须著录。
- **专著中析出文献**：`析出文献主要责任者. 析出文献题名[M]//专著主要责任者. 专著题名. 出版地: 出版者, 出版年: 页码.`

## 4. 正文引用标注

**顺序编码制**：
- 引文处标序号，通常上标：研究表明…效果显著<sup>[1]</sup>（Word 中字体-上标）
- 引用作为句子成分时不上标：文献[2]提出了…（"文献[2]"作为主语）
- 多个连续引用合并：[1-3]；不连续：[1,4,7]
- 序号按正文首次出现顺序编排；文献表按序号排列
- 同一文献多次引用用同一序号，可在方括号外标注页码：…[8]15

**著者-出版年制**：
- (作者, 年份)或"作者(年份)指出…"
- 中文作者用姓名；两位作者"和"连接：(张三和李四, 2020)；3 位以上：(张三等, 2020)
- 西文作者：(Smith & Jones, 2021)或(Smith et al., 2021)
- 文献表按语种（通常中文在前西文在后）及作者字顺排列

## 5. 常见错误清单（校对必查）

- [ ] 文献类型标识码与实际类型相符（学位论文误标 [J] 最常见）
- [ ] 期刊页码、卷期完整；学位论文有授予单位与城市
- [ ] 电子资源"更新日期/引用日期/URL"齐全
- [ ] 作者超过 3 位时正确使用"等/et al"
- [ ] 中英文标点未混用（中文文献逗号顿号、西文文献半角）
- [ ] 正文序号与文献表条目一一对应，无缺号、跳号
- [ ] 年份卷期等数字为半角数字
- [ ] 文献表内条目格式风格统一（同一语言内部）
- [ ] 无编造文献（每条可溯源）

## 转换与批量处理

用户提供原始文献信息（混乱格式、BibTeX、EndNote 导出等）时：
1. 先识别每条的类型（专著/期刊/学位论文…）
2. 按第 3 节模板逐条重排
3. 按正文引用顺序重新编号（顺序编码制）
4. 输出对照表（原条目 → 规范条目）供用户核对，最后给出可直接粘贴的文献表
5. 大批量（>30 条）可在 `.temp/` 写 Python 脚本半自动处理，人工规则再修正

## 6. 批量格式化工具（tools/citation_formatter.py）

**首选方式：调用本技能自带脚本**（v1.4 新增）——规则性任务用代码执行，同一输入永远同一输出（零漂移）：

```bash
# 零参数 = 满意初版：GB/T 7714 顺序编码制
python tools/citation_formatter.py 引文.txt

# 微调参数：著者-出版年制 / 按作者排序 / 对照表 CSV
python tools/citation_formatter.py 引文.txt --style author_year
python tools/citation_formatter.py 引文.txt --sortby author
python tools/citation_formatter.py 引文.txt --out_format csv

# 一键自验（samples/ 混乱引文 20 条）
python tools/citation_formatter.py --demo
```

输入格式：txt 文件每行一条（支持断行续写、`#` 注释行、全角标点、带/不带序号）。

**四步流水线**：字段解析（作者/年份/标题/来源/卷期/页码/DOI，中西文分别处理）→ 类型判定（已有标识采信；无标识按特征推断：有卷期页→[J]、有学校→[D]、有出版社→[M]、有URL→[EB/OL]）→ 国标重排（>3位作者加"等/et al."、西文姓前名缩写如 SMITH J、页码连字符统一）→ 输出三件套。

**输出三件套**（默认 `.temp/citations/`）：
1. `参考文献_国标.md`：规范条目（可直接粘贴论文）
2. `对照表.md`（或 CSV）：原文→国标逐条对照，含类型与置信度
3. `待复核清单.md`：类型中/低置信 + 字段缺失/解析存疑条目（含具体原因），**必须人工核对后再定稿**

**处理边界（诚实声明）**：
- 标准号（GB/T 7714-2015）、专利号（CN2023…）内的年份可能与出版年混淆——已按"解析存疑"降级进待复核清单
- 机构作者（如部委、标准化委员会）容易落入标题位——会提醒"作者未识别"
- 纯 URL 条目无法补全标题/日期——列入待复核，建议用户访问补全
- 设计原则：**宁可多提醒、不可静默出错**；自动处理约 80% 常规条目，剩余 20% 边界条目透明标记

**批量工作流四步法**：整批导入 → 生成对照表 → 人工复核待复核清单 → 定稿。不要跳过第 3 步。

## 7. 智能体工作流（技能加载后使用）

### 7.1 引文格式体检

用户把**已写好的参考文献段**（论文里复制出来）发来时：
1. 逐条对照第 5 节常见错误清单检查（标识码错、全半角、作者规则、缺要素、序号断裂）
2. 可调用 `citation_formatter.py` 解析对照（原文是否已合规、哪里不规范）
3. 输出问题清单：每条给出「问题定位 + 错误类型 + 修正示例」，按严重度排序
4. 询问是否执行批量修正

### 7.2 引文真伪核验与元数据补全（tools/citation_verifier.py）

AI 时代编造文献是学术公害（调研：Nature 调查 60%+ 科研人员遇到 AI 文献幻觉；"查无此书的参考文献，AI 写得有模有样"）。**本技能已实做核验工具**（v1.5，基于 Crossref 学术 DOI 权威元数据 API，免费公开接口）：

```bash
# 真伪核验：逐条联网检索，输出核验报告（已验证/高置信匹配/存疑/无法核验 + 证据链接）
python tools/citation_verifier.py 引文.txt --verify

# 核验 + 元数据补全：缺失的 DOI/卷/期/页码自动补齐（只补缺失，不覆盖已有），并输出补全后文献表
python tools/citation_verifier.py 引文.txt --verify --enrich
```

**核验机制**（三层判定）：
1. **DOI 直查**（最可靠）：有 DOI 的条目直接查 Crossref 权威元数据 → `✓ 已验证`
2. **标题+作者+期刊检索**：无 DOI 条目按标题检索，相似度 ≥0.85 判高置信匹配（短标题叠加期刊名一致性加成防同名词误配）→ `✓ 高置信匹配`
3. **未命中** → `⚠ 存疑待复核`（**不是编造**——中文文献 Crossref 覆盖有限，请转知网/谷歌学术人工确认）

**元数据补全**（解决调研发现的第一痛点："知网导出只有标题作者，没有 DOI、卷期页码，手动补全耗掉整个下午"）：
- 对核验命中的条目，用 Crossref 权威元数据补全缺失字段（DOI/卷/期/页码/来源），**只补缺失、不覆盖已有**
- 补全后自动重新格式化，输出新的国标文献表

**实测效果**（samples 样例集 20 条）：真实西文文献 5/5 全部命中（含 1 条 DOI 直查、4 条标题检索，自动补全 DOI/卷期）；编造条目与中文条目正确标"存疑"；判定边界严格执行——报告每条附来源链接，可追溯。

**判定边界（必须遵守）**：未命中 ≠ 编造；只输出核验状态与证据，不下"编造"结论，最终判断权归用户。

**年份结构体检**（v1.6 新增）：`python tools/citation_verifier.py 引文.txt --year-report` —— 本地解析不联网，输出总数评估（30-60 条申报书口径）、**近 5 年占比**（"参考文献陈旧"是明文毙稿原因）、年份分布直方、缺年份清单；`--verify --enrich` 的核验报告末尾亦自动附加该分析段。
