## 1. 润色工作流程与原则

**流程**：通读全文把握主旨 → 诊断问题（语言/逻辑/格式分层列出）→ 分层润色 → 输出修改稿 + 修改说明。

**原则**：
- 保留作者原意，不改变观点、数据、结论
- 重大改动（删段、重组结构）先向用户说明理由，确认后执行
- 每次润色输出修改说明：改了什么、为什么改，便于作者学习与复核
- 降重请求：只提供正当的表述改写（同义转换、句式重组、语序调整），并提醒用户观点与数据必须原创

## 2. 语言润色：口语化→学术化

高频替换对照表：

| 口语化 | 学术化 |
|---|---|
| 我觉得/我认为 | 笔者认为/本文认为 |
| 很多/特别多 | 大量、多数、相当比例 |
| 差不多 | 近似、大致相当 |
| 越来越重要 | 日益凸显、日趋重要 |
| 好处/坏处 | 优势/局限性、积极影响/消极影响 |
| 搞清楚 | 阐明、揭示、厘清 |
| 用了…方法 | 采用…方法/基于…方法 |
| 做了个实验 | 开展了实验/实施了实验验证 |
| 证明了（非严格证明） | 表明、验证了、证实 |
| 很厉害/先进 | 显著优于、性能优异 |
| 现在还不知道 | 尚未明确、有待探究 |

其他语言问题：
- 冗余：删"进行了…的研究"→"研究了"；"存在着"→"存在"；"由于…的原因"→"由于…"
- 长句拆分：一句话超过 2 个逗号层次或 60 字，考虑拆分
- 量化表达：模糊词（"较高""一定程度上"）能量化则建议用户量化
- 语气适度：避免绝对化（"完美解决""彻底消除"），学术表达留余地（"有效缓解""显著降低"）
- 连接词升级：但是→然而/相比之下；所以→因此/由此可见；还有→此外/进一步地

## 3. 逻辑与结构润色

**段落层面**：
- 每段一个中心思想，主题句居首
- 段内顺序：观点 → 论据/数据 → 小结
- 删除与段落中心无关的句子（向用户说明）

**篇章层面**：
- 检查论证链条：引言提出的问题 → 方法回应 → 结果回答 → 结论呼应，前后闭环
- 章节标题逻辑递进（并列式或递进式统一，不混杂）
- 引言承诺的内容与正文实际内容一一对应（引言写了 4 个部分，正文必须有 4 个部分）
- 结论不引入新数据、新观点

**衔接检查**：段落间需要过渡词/过渡句；缺失时补充"基于上述结果…""为进一步验证…"等衔接语。

## 4. 格式规范润色

- **术语一致性**：全文同一概念统一称谓（做术语表逐对检查，如"算法A/该算法/A 算法"不混用）
- **缩写规范**：首次出现给全称"卷积神经网络（Convolutional Neural Network, CNN）"，此后统一用缩写；题目与摘要中慎用缩写
- **数字规范**：GB/T 8170 有效数字；统计量保留位数一致；单位符号（% 前、单位间空格，如 "35.6 kg"）
- **图表交叉引用**：正文中每个图表都被引用；图表编号连续；引用位置在图表首次出现之后（或紧邻）
- **参考文献**：按 citation-gbt7714.md 校对
- **标题层级**：1 → 1.1 → 1.1.1，不跳级
- **标点**：中文全角标点；括号内完整句子句号在括号内；数据区间用"~"或"—"全文统一

## 5. 题目与摘要专项优化

**题目**：
- 中文 ≤25 字（学位论文可放宽），避免"基于…的…研究"空洞模板堆叠
- 结构建议：对象 + 方法/视角 + 问题，如"基于多源数据融合的城市交通流短时预测方法"
- 突出创新点与范围限定词；不用非公知缩写

**摘要**（四要素结构）：
```
【目的】针对…问题/为解决…
【方法】采用/构建/提出…方法，通过…实验/数据…
【结果】结果表明：…（量化结果，至少 2-3 个关键数据）
【结论】本研究为…提供了…（意义与局限可选）
```
- 中文摘要 300-500 字（学位论文可到 600 字）；英文摘要与中文对应，非逐句翻译
- 关键词 3-8 个：核心概念 2-4 个 + 方法 1-2 个 + 领域 1 个；从题名与摘要中提炼；不用过于宽泛的词（如"研究""应用"单独作关键词）

**英文摘要语言要点**：时态（目的/结论用现在时，方法/结果用过去时）；语态适度主动；避免中式直译（"with the development of…"开头等陈词滥调）。
