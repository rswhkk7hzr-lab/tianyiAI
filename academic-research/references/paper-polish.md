## 1. 润色工作流程与原则

**流程**：通读全文把握主旨 → 诊断问题（概念/语言/逻辑/格式四层列出，概念层优先级最高）→ 分层润色 → 输出修改稿 + 修改说明。

**原则**：
- 保留作者原意，不改变观点、数据、结论；**但概念性/事实性错误属客观错误，不属"观点"范畴**——须标记、给出证据，经用户确认后修正（见第 3 节边界规则）
- 重大改动（删段、重组结构、概念修正）先向用户说明理由，确认后执行
- 每次润色输出修改说明：改了什么、为什么改，便于作者学习与复核
- 降重请求：只提供正当的表述改写（同义转换、句式重组、语序调整），并提醒用户观点与数据必须原创

## 2. 语言润色：口语化→学术化

高频替换对照表：

| 口语化 | 学术化 |
|---|---|
| 我觉得/我认为 | 笔者认为/本文认为 |
| 很多/特别多 | 大量、多数、相当比例 |
| 差不多 | 近似、大致相当 |
| 越来越重要 | 日益凸显、日趋重要 |
| 好处/坏处 | 优势/局限性、积极影响/消极影响 |
| 搞清楚 | 阐明、揭示、厘清 |
| 用了…方法 | 采用…方法/基于…方法 |
| 做了个实验 | 开展了实验/实施了实验验证 |
| 证明了（非严格证明） | 表明、验证了、证实 |
| 很厉害/先进 | 显著优于、性能优异 |
| 现在还不知道 | 尚未明确、有待探究 |

其他语言问题：
- 冗余：删"进行了…的研究"→"研究了"；"存在着"→"存在"；"由于…的原因"→"由于…"
- 长句拆分：一句话超过 2 个逗号层次或 60 字，考虑拆分
- 量化表达：模糊词（"较高""一定程度上"）能量化则建议用户量化
- 语气适度：避免绝对化（"完美解决""彻底消除"），学术表达留余地（"有效缓解""显著降低"）
- 连接词升级：但是→然而/相比之下；所以→因此/由此可见；还有→此外/进一步地

## 3. 概念修正：术语与事实性错误检查

语言润色解决"说得不像学术"，概念修正解决"说得不对"。两者独立成层，概念层优先级最高。

### 高频概念混淆对照表（发现即标记）

**统计类**：
| 常见误用 | 正确理解 |
|---|---|
| "p 值是原假设为真的概率" | p 值是原假设为真时观察到当前及更极端结果的概率；不能宣称"假设为真的可能性" |
| "统计显著 = 效应量大/实际重要" | 显著性受样本量影响；须结合效应量与置信区间讨论实际意义 |
| 显著性水平 α 与 P 值混用 | α 是事前设定的拒绝门槛；P 值是事后计算的结果 |
| 信度/效度混用 | 信度是一致性（重复测量稳定），效度是准确性（测到所要测的） |
| 相关/回归系数显著 → 直称因果 | 相关与因果必须区分；因果结论需设计（随机化/纵向）支撑 |
| "95% 置信区间有 95% 概率包含真值" | 置信水平指重复抽样下区间覆盖真值的长期频率，单个区间无概率意义 |

**机器学习类**：
| 常见误用 | 正确理解 |
|---|---|
| 准确率/精确率/召回率混用 | 准确率=总判对比例；精确率=预测为正中真为正；召回率=真为正中被找出 |
| 用测试集调参/选模型 | 模型选择与调参用验证集（或交叉验证），测试集只在最终评估用一次 |
| 过拟合/欠拟合混称 | 过拟合=训练好测试差；欠拟合=训练测试都差 |
| 把交叉验证当作增大数据量 | 交叉验证用于稳健的模型选择与评估，不产生新数据 |

**研究方法类**：
| 常见误用 | 正确理解 |
|---|---|
| 内部效度/外部效度混用 | 内部效度=因果推断有效性；外部效度=结论可推广性；两者常相互制约 |
| 横断面研究下因果结论 | 横断面只代表某时点关联，不能排因果时序 |
| 准实验直接称 RCT | 随机对照试验须真随机分配；未随机化的只能称准实验/类实验 |
| 系统综述与荟萃分析互代 | 系统综述是方法学框架，可不含定量合并；荟萃分析专指定量合并效应量 |

### 概念修正流程

1. **识别**：对照上表 + 学科常识扫描全文，标记疑似误用点（含术语全文不一致：同一概念多种称谓混用）
2. **溯源**：查权威定义/文献确认（不凭记忆下结论）；涉及具体文献论断时，转入 citation-gbt7714.md 的 L3 支持性核验
3. **报告**：向用户输出"错误位置 + 错误类型 + 证据 + 建议改法"清单，**经确认后**才改稿
4. **修正**：修改稿中落实，修改说明表逐条留痕（理由列须给出依据来源）

### 边界规则（与"不改观点"的关系）

- **概念/事实错误**（如上表）：客观错误，标记 + 建议修正 + 用户确认后执行
- **作者观点/表述风格**：尊重原意，只做语言优化
- **拿不准是否为错**（学科争议、新兴术语、作者可能有意为之）：标注存疑并说明两种理解，交用户裁决，不擅自修改

## 4. 逻辑与结构润色

**段落层面**：
- 每段一个中心思想，主题句居首
- 段内顺序：观点 → 论据/数据 → 小结
- 删除与段落中心无关的句子（向用户说明）

**篇章层面**：
- 检查论证链条：引言提出的问题 → 方法回应 → 结果回答 → 结论呼应，前后闭环
- 章节标题逻辑递进（并列式或递进式统一，不混杂）
- 引言承诺的内容与正文实际内容一一对应（引言写了 4 个部分，正文必须有 4 个部分）
- 结论不引入新数据、新观点

**衔接检查**：段落间需要过渡词/过渡句；缺失时补充"基于上述结果…""为进一步验证…"等衔接语。

## 5. 格式规范润色

- **术语一致性**：全文同一概念统一称谓（做术语表逐对检查，如"算法A/该算法/A 算法"不混用）；概念层误用按第 3 节流程处理
- **缩写规范**：首次出现给全称"卷积神经网络（Convolutional Neural Network, CNN）"，此后统一用缩写；题目与摘要中慎用缩写
- **数字规范**：GB/T 8170 有效数字；统计量保留位数一致；单位符号（% 前、单位间空格，如 "35.6 kg"）
- **图表交叉引用**：正文中每个图表都被引用；图表编号连续；引用位置在图表首次出现之后（或紧邻）
- **参考文献**：按 citation-gbt7714.md 校对
- **标题层级**：1 → 1.1 → 1.1.1，不跳级
- **标点**：中文全角标点；括号内完整句子句号在括号内；数据区间用"~"或"—"全文统一

## 6. 题目与摘要专项优化

**题目**：
- 中文 ≤25 字（学位论文可放宽），避免"基于…的…研究"空洞模板堆叠
- 结构建议：对象 + 方法/视角 + 问题，如"基于多源数据融合的城市交通流短时预测方法"
- 突出创新点与范围限定词；不用非公知缩写

**摘要**（四要素结构）：
```
【目的】针对…问题/为解决…
【方法】采用/构建/提出…方法，通过…实验/数据…
【结果】结果表明：…（量化结果，至少 2-3 个关键数据）
【结论】本研究为…提供了…（意义与局限可选）
```
- 中文摘要 300-500 字（学位论文可到 600 字）；英文摘要与中文对应，非逐句翻译
- 关键词 3-8 个：核心概念 2-4 个 + 方法 1-2 个 + 领域 1 个；从题名与摘要中提炼；不用过于宽泛的词（如"研究""应用"单独作关键词）

**英文摘要语言要点**：时态（目的/结论用现在时，方法/结果用过去时）；语态适度主动；避免中式直译（"with the development of…"开头等陈词滥调）。

## 7. 多语言与英文学术写作

### 语言选择与期刊适配

- 先确认目标语言：中文期刊（GB 体例）vs 英文期刊（SCI/SSCI，APA/Vancouver/期刊自定体例）
- 双语期刊按投稿须知；未指定时按用户写作语言交付
- 中英体例差异要点：标点（中文全角/英文半角不混用）、数字（英文千分位逗号、小数点）、首行缩进（中文 2 字符 / 英文 0.5 in 或段落空行）、参考文献体例（GB/T 7714 vs 期刊体例，见 citation-gbt7714.md）

### 英文学术写作规范

- **时态**：目的与结论现在时；方法、结果过去时；公认事实现在时（"Water boils at 100 °C"）
- **hedging 缓和语**：claim 强度与证据强度匹配——单个观察性研究用 suggests / is associated with，不用 proves / demonstrates causally；避免双重堆叠（might possibly）
- **句式**：主语尽早出现；一段一个中心句；避免超长名词串（"the user behavior data analysis result evaluation method"）
- **连接词**：However / Therefore / In contrast / Furthermore 段首衔接；避免中式英语高频错误（researches 作可数名词、according to 滥用、with the development of 开头）
- **主动/被动**：方法段适度被动可接受（The samples were incubated…），但避免全文被动堆叠

### 术语双语对照表

中英转换前先建术语表，全文与图表统一：

| 中文术语 | 英文术语 | 首次出现写法 | 备注 |
|---|---|---|---|
| 剂量-反应关系 | dose-response relationship | dose-response relationship（下同 D-R）| 全文统一用词，不同译法不混用 |
| 偏倚风险 | risk of bias | risk of bias | … |

- 英文首次出现给全称+缩写："risk of bias (RoB)"，此后统一用缩写；题目与摘要慎用缩写
- 同一术语只用一种译法（如"随机对照试验 RCT"不与"临床对照试验"混用）；图表与正文一致

### 中文稿→英文稿转换流程

1. **术语表先行**：核心术语 20-50 个定译后再动笔，避免返工
2. **翻译性改写**：按段落重写，不逐句直译；句序按英文习惯重组（中文尾重点→英文头重点）
3. **语言润色**：按本节英文学术规范与第 2 节口语化替换的英文对应处理
4. **双语校对**：逐段核对数字、单位、统计量与中文稿一致；图表数据逐一比对
5. **体例适配**：参考文献、图表标注、页边距按目标期刊调整；交付按 document-export.md

### 边界声明

语言编辑只改表达不改内容：观点、数据、结论与中文稿一致；概念性错误按第 3 节流程标记确认后再改。英文润色建议作者自查或经母语润色服务复核关键段落。
